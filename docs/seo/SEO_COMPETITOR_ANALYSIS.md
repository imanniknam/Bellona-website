## Competitor types

| Type | What it means for Bellona |
|---|---|
| **A. Direct — AI automation / agent agencies** | Same offer, same buyer. Most important set. |
| **B. Direct — web design / development agencies** | Compete for Bellona's biggest-demand service (web design). Mature, content-heavy. |
| **C. Substitutes — AI chatbot & CRM/office-automation SaaS** | Buyer may choose software instead of an agency. They dominate "chatbot" and "sales automation" SERPs. |
| **D. Publishers / course providers** | Own informational SERPs (n8n, AI agent). Not commercial rivals, but block visibility. |
| **E. Marketplaces & directories** | Freelance platforms and "best company" lists — both competitors and listing opportunities. |

## Comparative findings

1. **No direct competitor combines web + product + AI automation + growth with real case studies on one site.** Ayratech is closest. Bellona's integrated "lead → AI agent → CRM → analytics" story is distinctive — but currently unsupported by results data.
2. **AI-automation commercial SERPs are soft.** A 280-word page (Kados) and an H1-less homepage (MihanAI) rank on page one. A deep, proof-backed Persian page has a realistic chance.
3. **Web-design SERPs are hard.** Mature agencies with 1,300–10,000-word pages, listicles and sponsored PR dominate. Bellona should enter via **niches** (Next.js, bilingual/RTL, education platforms) rather than the head term.
4. **Pricing transparency is normal** in Iranian web-design and AI SERPs (1405 price pages, from-prices). Bellona already exposes budget brackets in its form — it can publish honest ranges.
5. **Informational AI/n8n SERPs belong to publishers and course sellers** (Zoomit, Faradars, Maktabkhooneh, Ivira). Bellona should only publish informational content where it adds first-hand implementation detail (e.g., self-hosted n8n in Iran, real cost breakdowns from its projects).
6. **Sponsored "reportage" (رپورتاژ) is widespread** (zoomit.ir/pr, digiato.com/promoted, gadgetnews.net appearing for "best web design company in Tehran"). If Bellona buys such placements, links must carry `rel="sponsored"`; buying followed links violates Google's spam policies.

| Education-platform design & gamified learning | 3 of 4 case studies are education | Konjed, Codechee, Microshamim |
| n8n implementation service for Iranian businesses | SERP shows hiring intent (Karlancer) and hosting demand (Iranserver, Hamravesh) but few agency service pages | `اتوماسیون n8n` SERP |
| Honest AI-agent cost guide with real Bellona ranges | Matches #1 SERP format (Ivira) with first-hand data | `هزینه ساخت ایجنت هوش مصنوعی` SERP |
| Integration positioning (connect site + CRM + AI) | CRM vendors sell software; few explain integration | `اتوماسیون فروش و crm` SERP all vendors |

## Watch-outs

- **Brand collision:** "بلونا" SERP = Wikipedia (Roman goddess), furniture brand (Digikala, Sofadatis, Balad), clothing (Instagram), wholesaler. Use "آژانس بلونا" / "بلونا ایجنسی" consistently and build entity signals.
- Do not copy competitor structures wholesale; use them only to understand what the SERP rewards.
